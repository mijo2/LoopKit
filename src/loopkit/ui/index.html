loop-kit

Try the loop loaded in this process. In a program, call Loop.ask.

    Enter sends, Shift+Enter adds a line. The earlier turns of this chat go with each ask and the server folds them into one task; open “Details” on an answer to see exactly what the loop received. With --session, chats are kept in a file and come back after a refresh.

    Advanced options

    Settings for this tab only, used by its next ask. A tab opened with + starts from the settings of the tab it was opened from, then changes on its own. They are the arguments of Loop(...); the knowledge base read at startup stays in memory.

    Knowledge
    Read as one document. Markdown headings become passage headings.
    Instructions
    Leave empty for the built-in instructions (shown greyed). Each line is checked on its own.
    Model
    For an OpenAI-compatible server (Ollama, vLLM, LM Studio, …). Implies the compatible provider.
    Loop
    Check mode
    each: one model call per instruction, then grounding. all: every instruction in one call.
    Response
    book asks for a long response with headings and raises the output cap.
    A knowledge base under this size is sent whole; otherwise BM25 keeps the top k passages.
